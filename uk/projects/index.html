Проєкти: ПЗ для БпАК

Двенадцать программных проектов от веб-GCS до точной посадки по маркеру. Каждый — с архитектурной схемой, этапами, критериями готовности и автотестом; там, где написан стартер, он лежит в examples/ репозитория. Проект может заменить итоговый проект своего трека.

Как работать: возьмите проект, пройдите модули из его списка, сделайте этапы по порядку, проверьте себя по критериям готовности и автотестам. Код — в собственном репозитории с README и тестами; «работает у меня» критерием не считается.
