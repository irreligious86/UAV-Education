КурсПроектыПроект 9

Мост 4G/Wi-Fi с переподключением и шифрованием

Проект 9L3~25 честь стартерСДАН

Companion держит связь GCS ↔ аппарат через сотовую сеть: VPN (WireGuard), маршрутизация MAVLink, переподключение, приоритет команд над телеметрией и поведение при потере канала.

Стек

  • WireGuard
  • mavlink-router
  • Python или Go
  • tc/netem для имитации плохой сети

Стартер: examples/cell-bridge — клонируйте и начинайте с его README.

Может заменить итоговый проект трека «Инженер: код на борту».

Этапы

  1. VPN между companion и сервером, автоподнятие
    Проверка: демонстрация в отчёте
  2. Маршрутизация MAVLink через туннель
    Проверка: pytest examples/cell-bridge/tests -k control_never
  3. Имитация потерь и задержек (netem), замеры
    Проверка: pytest examples/cell-bridge/tests -k commands_get_through
  4. Снижение частоты телеметрии при плохом канале
    Проверка: pytest examples/cell-bridge/tests -k bad_link
  5. Failsafe на стороне аппарата при потере GCS — проверен
    Проверка: pytest examples/cell-bridge/tests -k outage

Критерии приёмки

Проект сдан, когда выполнены все пункты. Отмечайте по мере готовности:

Автопроверка

тест на netem: потери, задержка, разрыв

Оценка

Сдан — когда выполнены все критерии приёмки. Уровень работы — по критериям ниже; каждый уровень включает предыдущий.

  • Функциональность
    • Засчитано: Все этапы работают в сценарии из README
    • Хорошо: Плюс отказные сценарии: потеря связи, пропуск данных, неверный ввод
    • Отлично: Плюс хотя бы одно задание «на отлично» из списка проекта
  • Проверяемость
    • Засчитано: Тесты стартера проходят, свои функции покрыты хотя бы одним тестом
    • Хорошо: Тест на каждый этап; тесты запускаются в CI
    • Отлично: Тесты на отказы и регрессию на собственных данных; покрытие ключевой логики видно в отчёте
  • Инженерный отчёт
    • Засчитано: Есть замеры, которых требуют критерии приёмки
    • Хорошо: Замеры с методикой и повторяемостью (несколько прогонов, разброс)
    • Отлично: Сравнение вариантов решения с выводом, ограничения и что делать дальше
  • Код и документация
    • Засчитано: README: запуск одной командой, архитектура
    • Хорошо: Модули разделены, интерфейсы описаны, нет «магических чисел» без пояснения
    • Отлично: Код читается без автора: docs/, примеры, история коммитов по этапам

Задания «на отлично»

  • Переключение Wi-Fi ↔ 4G без потери команды
  • Замер стоимости трафика за час полёта и бюджет телеметрии под тариф

Что сдать

  • Конфиги, скрипты, отчёт с замерами

Нужные модули

  1. Маршрутизация и транспорт MAVLink: радио, 4G, несколько GCS
  2. Raspberry Pi + ArduPilot
  3. Устойчивость навигации и связи к помехам
  4. Отказоустойчивость: failsafe, геозона, FMEA полёта
Безопасность. Всё, что управляет аппаратом, сначала проходит тесты и SITL. Реальный полёт — только с проверенным failsafe и пилотом, готовым забрать управление.
