Глоссарий

PID

Пропорционально–интегрально–дифференциальный регулятор контура стабилизации.

MAVLink

Micro Air Vehicle Link — легковесный протокол обмена данными между БПЛА и наземными станциями. MAVLink 2 поддерживает подписанные сообщения и расширенную адресацию.

Blackbox

Система логирования полетных данных в Betaflight для анализа производительности, вибраций и работы PID-регуляторов.

SITL

Software In The Loop — симуляция полета на компьютере для безопасной отладки и тестирования миссий без реального дрона.

UART

Universal Asynchronous Receiver-Transmitter — последовательный интерфейс связи FC с периферией.

CRSF

Crossfire-протокол связи между приемником и FC, используется в TBS Crossfire и ExpressLRS.

ELRS

ExpressLRS — открытый протокол радиосвязи с низкой задержкой и высокой дальностью. Популярная альтернатива Crossfire.

Gyro

Гироскоп — датчик угловой скорости, основа стабилизации в полетных прошивках.

D-term

Дифференциальная составляющая PID-регулятора, подавляет резкие колебания и bounce-back.

uORB

micro Object Request Broker — шина сообщений в PX4 для обмена данными между модулями по принципу publish/subscribe.

EKF

Extended Kalman Filter — фильтр, объединяющий данные с датчиков для точной оценки положения, скорости и ориентации дрона.

VTOL

Vertical Take-Off and Landing — аппарат с вертикальным взлетом/посадкой и горизонтальным полетом.

RTK GPS

Real-Time Kinematic — высокоточное позиционирование с точностью до сантиметров для профессиональных задач.

DShot

Digital Shot — цифровой протокол связи между FC и ESC, обеспечивающий точное управление моторами по сравнению с PWM/Oneshot.

IPF

INAV Programming Framework — система программирования в INAV для создания пользовательской логики поведения.
