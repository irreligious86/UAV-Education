ReferenceSetup-from-scratch cards

Setup cards from scratch

One card per firmware, the course's 17 setup steps in the same order. Each row says where the step is done, what to set or check (parameter names, units, calibration formulas) and how you know the step is closed. Details and explanations are in the module linked above each card. The cards are handy to print and tick off on the bench.

Environment: SITL — checked in the simulator, bench — on the bench without props, field — outdoors, in flight or under open sky (compass, GPS).

  • Betaflight 2025.12
  • INAV 9.1 — quadcopter, the flying wing variant
  • ArduCopter 4.7
  • PX4 1.18

Betaflight 2025.12

Module: Betaflight from scratch: from a blank board to the first hover. Version: 2025.12 (checked against 2025.12.5; the steps marked SITL were captured on SITL from the 4.5-maintenance branch: version.h says 4.5.6, but the code is the 4.5.5 release apart from the version number). “Where”: a Betaflight App tab (before 2025.12, Betaflight Configurator) / a CLI command. The 4.5 → 2025.12 renames are in bf-intro.

Propellers off. Props go on only at step 15. The first power-up after soldering goes through a smoke stopper; before you plug in the battery, a multimeter between + and − reads at least hundreds of ohms.
Step · environmentWhereWhat to set / checkDone when
1. Firmware, backup
SITL bench		Firmware Flasher; CLIBefore flashing: diff all of the old config to a file. The board's target, a Cloud Build with the options for the aircraft (CRSF, DShot, OSD — analog or HD, GPS, magnetometer if present, VTX protocol), Full chip erase; do not paste a 4.5 diff all as a whole. SITL: make TARGET=SITL, CLI — # on TCP 5761the old diff all is saved to a file
2. Orientation, mixer
SITL bench		Setup; CLI mixer, align_board_*mixer → Mixer: QUADX. If the board is rotated, align_board_yawthe model on the Setup tab follows the aircraft's tilts
3. UART ports
SITL bench		Ports; CLI serial (CLI only in SITL)Receiver UART → Serial RX (function 64); GPS → GPS; VTX → Peripherals: SmartAudio or Tramp (analog), MSP + osd_displayport_device = MSP (HD)every device is on its own UART, checked on the board
4. Receiver, bind
bench		Receiver; CLIReceiver: Serial, serialrx_provider = CRSF. ELRS bind: binding phrase, the ELRS major versions on TX and RX match (4.x with 4.x; 3.x does not link with 4.x). The built-in SPI receiver under 2025.12 is ELRS 3: with a 4.x module you need a separate receiver on a UARTthe Receiver bars move, status has no RXLOSS
5. Channels, end points, centers
bench		Receiver; CLI mapmap AETR1234. CRSF gives 988–2012 µs. Roll, pitch and yaw centers 1500 ± 5; throttle at the bottom below min_check = 1050 (otherwise the THROTTLE flag), at the top above max_check = 1900; AUX positions no closer than 50 µs to a mode range boundarythe channel table is filled in, every channel moves in its own direction
6. Motor protocol
bench		Motors; CLImotor_pwm_protocol = DSHOT600 or DSHOT300. Bluejay, BLHeli_32, AM32: dshot_bidir = ON, motor_poles = 14. SITL has no DShot — use PWM thereno MOTOR_PROTO flag, no telemetry errors on any of the four motors in Motors
7. Order and direction
bench		Motors: Reorder motors, Motor direction; CLI motor_output_reordering, dshotprogQUADX (props in, yaw_motors_reversed = OFF): 1 rear right CW, 2 front right CCW, 3 rear left CCW, 4 front left CW. Sliders one at a time up to ~1100. Order: motor_output_reordering = 1,0,2,3,4,5,6,7 (an example, with set). Direction: dshotprog 2 8 12 (index from 0, 255 — all; 7/8 — direction, 12 — save). There is no motor_direction parameterall four motors match QUADX in position and direction, save
8. ESC calibration (PWM, OneShot, Multishot only)
bench		Motors, master sliderBattery unplugged, motor test enabled, master at 2000 → plug in the battery → after the “maximum” tone, master to 1000 → confirmation → unplug the battery. Limits: min_command = 1000, max_throttle = 2000 (min_throttle from 4.5 was removed in 2025.12; idle is motor_idle). DShot is not calibratedall motors start at the same slider value (difference ≤ 10 µs)
9. Accelerometer
SITL bench		Setup → Calibrate Accelerometeron a level table; the result is get acc_calibration, the fourth number 1the ANGLE flag disappears from status when the aircraft sits level
10. Voltage and current
bench field		Power & Battery; CLIbattery_meter = ADC, current_meter = ADC, bat_capacity. Voltage ∝ vbat_scale (default 110): new = old × V_multimeter / V_FC, a step of 1 ≈ 0.9 %. Idle current: ibata_offset (mA) new = old + (I_ammeter − I_FC) × 1000. Current ∝ 1/ibata_scale (mV per 10 A, 400 = 40 mV/A): new = old × mAh_FC / mAh_charged. Offset first, then scale. Example: 110 → 112, 0 → 230, 400 → 351voltage error below 50 mV per cell on a full and on a storage cell (≈ 3.85 V); FC mAh within 5 % of the charger's
11. Modes, arming, blocks
SITL		Modes; CLI aux, statusaux 0 0 0 1700 2100 0 0 (ARM, AUX1), aux 1 1 1 1300 2100 0 0 (ANGLE, AUX2), aux 2 27 2 1700 2100 0 0 (FAILSAFE, AUX3). Flags of a clean SITL: RXLOSS ANGLE BOOTGRACE CLI MOTOR_PROTOthe switches light up ARM, ANGLE, FAILSAFE; arming works only with throttle below min_check
12. Failsafe: set up and test
SITL bench		Failsafe; CLI failsafe_*SITL: the FAILSAFE switch, failsafe_switch_mode = STAGE2, the default procedure DROP → disarmed, ARM_SWITCH (in 4.5 ARMSWITCH) prevents re-arming (RC loss cannot be tested in SITL). Bench: arm, switch off the TX module → Stage 1 failsafe_delay = 15 (1.5 s), then Stage 2Stage 2 is recorded on OSD video or in Blackbox, the OSD shows FAILSAFE
13. OSD and video
bench		OSD, Video Transmitterminimum: average cell voltage, mAh, LQ/RSSI, mode, timer, warnings. VTX on the bench at 25 mW and only with an antennaall elements are visible in the goggles
14. GPS and GPS Rescue (if there is a GPS)
bench field		CLI gps_*, gps_rescue_*gps_provider = UBLOX, 5 Hz or higher. 2025.12 defaults: gps_rescue_min_sats = 8 (the documentation recommends 10), gps_rescue_min_start_dist = 15 m (the documentation says 30 — check with get), gps_rescue_initial_climb = 10 m, gps_rescue_return_alt = 30 m, gps_rescue_ground_speed = 750 cm/s, ap_hover_throttle = 1275 (in 4.5 gps_rescue_throttle_hover), gps_rescue_allow_arming_without_fix = OFF. failsafe_procedure = GPS-RESCUE only after step 15; the first tests by switch with failsafe_switch_mode = STAGE1arming only with a confirmed home point; the first tests by switch over grass at 30–50 m
15. Preflight and first hover — the props go on here
field		—props in and tightened; status without flags except ARM_SWITCH (in 4.5 ARMSWITCH); the OSD shows 4.15–4.20 V per cell; Blackbox erased; ANGLE. A 10 × 10 m area, people no closer than 10 m. Hover at 1–1.5 m for 60 s. Disarm immediately if it tips or spins at liftoff. Land on: oscillations; hover throttle above 60 % or below 12 %; drift over 1 m in 5 s; below 3.5 V per cell; LQ dropped or video lost; a hot motor60 s of hover in the log, the hover throttle (median of rcCommand[3]) recorded
16. First tuning
field		Blackbox Explorer; filters, PID slidersgyro spectrum from the hover log → filters and the RPM filter, then the PID slidersa diff all is taken after every change
17. Log, backup, restore
SITL field		Blackbox; CLI diff allrestore: batch start, defaults nosave, the commands from the diff, save, diff all againthe set/aux/feature lines match; diff all with the date and version in git

INAV 9.1 — GPS quadcopter

Module: INAV from scratch: a GPS quadcopter. Version: 9.1 (checked against 9.1.0; the SITL output in the module was captured on 8.0.1). “Where”: an INAV Configurator tab / a CLI command. Moving from 8.x: the table in Introduction to INAV.

Propellers off. Props go on only at step 15. The first power-up goes through a smoke stopper or a bench supply limited to 1–2 A; nobody stands in front of the aircraft.
Step · environmentWhereWhat to set / checkDone when
1. Firmware, backup
SITL bench		Firmware Flasher; SITL tab; CLIdiff all of the old firmware to a file. The board's target, Full chip erase, a Configurator of the same major version. SITL: SITL tab → Start → Connect, or cmake -DSITL=ON, TCP 5760the original diff all is saved
2. Platform, mixer
SITL		Mixer; CLI platform_type, mmixthe Quad X preset → Load and apply = 4 mmix lines: 1 rear right CW, 2 front right CCW, 3 rear left CCW, 4 front left CW. Props out — motor_direction_inverted = ON. Board rotated — align_board_*diff all has four mmix lines
3. UART ports
SITL		Ports; CLI serial <n> <functions> …function mask: MSP = 1, GPS = 2, RX_SERIAL = 64, BLACKBOX = 128, MSP_OSD = 33554432. Typically serial 1 64 … (receiver on UART2), serial 2 2 … (GPS on UART3)the serial lines in the diff match the wiring
4. Receiver, bind
bench		Receiver; CLIreceiver_type = SERIAL, serialrx_provider = CRSF, the RX_SERIAL function (64) on the UART. In SITL, receiver_type = MSPthe RX flag goes away while frames arrive and returns 0.5 s after they stop
5. Channel map, end points, centers
SITL bench		Receiver; CLI map, min_check/max_checkmap AETR (the default, correct for CRSF). Throttle at the bottom below min_check (1100), at the top above max_check (1900); centers 1500 ± 5; AUX1 (ARM): below 1300 and above 1700. map TAER by mistake → the THR flagthe channel table is filled in
6. Motor protocol
bench		Outputs; CLIBLHeli_S, BLHeli_32, AM32: motor_pwm_protocol = DSHOT300; throttle_idle = 8 % (the 9.1 default, unchanged since 8.0; 15 % in 7.1). PWM ESCs: STANDARD or ONESHOT125 + calibration. SITL silently changes DSHOT300 to MULTISHOT — check on the bench onlythe real aircraft's diff all has the right protocol
7. Order and rotation
bench		Outputs (motor test); Mixer → Motor Mixer Wizardeach motor in turn up to ~1100, the number must match the Quad X position (step 2). Order: the Wizard; direction: reverse in the ESC configurator or swap two phase wiresorder and rotation match Quad X
8. ESC calibration (PWM, OneShot only)
bench		Outputs, master sliderBattery unplugged, test enabled, master at 2000 → plug in the battery → maximum tone → master to 1000 → confirmation → unplug the battery. DShot is not calibratedthe motors start together, the spread at ~1050 is no more than one or two ticks
9. Accelerometer, compass
bench field		Setup / Calibration; CLI align_magaccelerometer — 6 positions; compass outdoors, Calibrate Compass, mag_calibration_time = 30 s; declination inav_auto_mag_decl = ONheading ±10° at the four cardinal directions, distance to home ±2 m at 20 m
10. Voltage and current
bench field		CLIV = ADC · vbat_scale · 3300 / (4095 · 1000): new = old × V_multimeter / V_INAV. current_meter_scale (0.1 mV/A, 400 = 40 mV/A), current ∝ 1/scale: new = old × mAh_INAV / mAh_charged. current_meter_offset (0.1 mV): new = old + (I_INAV − I_ammeter) × scale. Order: scale from a flight that used more than 50 %, then offset, then a check flight. Example: 1100 → 1132, 400 → 435, 0 → 104. Then bat_cells, battery_capacity, warning and critical at 30 % and 20 % of capacityerror below 50 mV per cell; INAV mAh within 5 % of the charger's
11. Modes, arming, blocks
SITL		Modes; CLI aux, statusmode ids: ARM 0, ANGLE 1, NAV ALTHOLD 3, NAV RTH 10, NAV POSHOLD 11, FAILSAFE 27. Example: aux 0 0 0 1700 2100 (ARM, AUX1), aux 2 11 1 1300 1700 (POSHOLD, AUX2 in the middle). SITL does not arm without a simulator (CAL NAV ACC)aux lines for ARM, ANGLE, POSHOLD, RTH in the diff; on hardware status has no flags
12. Failsafe: set up and test
SITL bench field		CLI failsafe_*; Receiverfailsafe_procedure = RTH (default LAND); failsafe_delay = 5 (0.5 s); a channel outside rx_min_usec…rx_max_usec (885…2115) counts as lost; failsafe_throttle_low_delay = 0; leave failsafe_min_distance at 0; exit with a stick beyond failsafe_stick_threshold = 50. RTH needs GPS, a compass and a baro. Bench, not armed: switch off the radio → the RX flag, a warning in the OSD. Field: switch off the radio at 50–100 mRTH starts after 0.5 s; failsafe → RTH recorded in the log or on OSD video
13. OSD and video
bench		OSD; CLI osd_video_systemanalog: AUTO or PAL. HD: MSP_OSD on the air unit's UART; HDZero — HDZERO, Walksnail — AVATAR, DJI O4 / goggles with the INAV font — DJI_NATIVE (OSD type “INAV” in the goggles), stock DJI O3 — BFHDCOMPAT, Air Unit/Vista on WTFOS — DJIWTF. Minimum: voltage, mAh, satellites, distance and the home arrow, mode, LQ/RSSIall elements are visible in the goggles
14. GPS, home, RTH
SITL field		CLI nav_rth_*nav_rth_altitude = 3000 (30 m); AT_LEAST, climb first ON, landing ALWAYS are already the defaults; closer than nav_min_rth_distance (5 m) RTH does not fly. GPS in 9.1: Galileo and BeiDou are on by default, gps_ublox_nav_hz = 8 (before 9.1 they were off and the rate was 10); the module preset is on the GPS tab. Field: POSHOLD at 5–10 m, then RTH by switch from 30–50 m and from 100 m at 20 m altitudePOSHOLD holds the point within ±1–2 m; RTH from 100 m lands no further than 5 m from home
15. Preflight and first hover — the props go on here
field		—props per the rotation direction; a 3D fix with at least 10 satellites (gps_min_sats = 6 is the minimum for a fix), HDOP ≤ 2, home recorded; Blackbox on. Arm in ANGLE, 1–2 m, 60 s. Land on: shaking or oscillations; drift over 1 m/s in calm air; hover throttle above 60 %; a hot motor60 s of hover in Blackbox, the hover throttle recorded
16. First tuning
field		CLI; EZ Tunenav_mc_hover_thr = the hover throttle from the log (default 1300, 1380 in the example). 9.1 defaults (the same as in 8.x): gyro_main_lpf_hz = 60, dynamic_gyro_notch_enabled = ON. rpm_gyro_filter_enabled only with rpm telemetry. EZ Tune: ez_enabled = ONALTHOLD/POSHOLD neither sags nor jumps when engaged
17. Log, backup, restore
SITL field		Blackbox; CLI diff alldiff all with the date and version next to the first hover log. Do not move a SITL diff to a board as a whole: *_hardware = FAKE, receiver_type = MSP, gps_provider = FAKE and the TCP serial lines are SITL-onlyrestoring the diff from the file is tested, all lines match

Flying wing variant (INAV 9.1)

Module: INAV from scratch: a flying wing. Steps 1, 3, 4, 9, 13 and 17 are the same as for the quad; below is what is different or added for a wing.

Propellers off. The prop stays off until the first launch. Plug in the battery only while holding the wing; wear glasses when working with the motor.
What · environmentWhereWhat to set / checkDone when
Platform and mixer
SITL		Mixer: Airplane, the Flying Wing preset; CLIset platform_type = AIRPLANE, mmix 0 1.0 0.0 0.0 0.0, smix 0 1 0 50 0 -1, smix 1 1 1 50 0 -1, smix 2 2 0 -50 0 -1, smix 3 2 1 50 0 -1. Outputs of one timer share one function (timer_output_mode)the diff has platform_type and four smix rules
Motor and ESC
bench		Outputs; CLImany airplane ESCs do not understand the default ONESHOT125: motor_pwm_protocol = STANDARD or DSHOT300. motorstop_on_low/throttle_idle: ON and 8 % in 9.1 (since 8.0; OFF and 15 % in 7.1.2); ON is convenient for a wingat low throttle the airflow from a paper strip goes backward, away from the wing
Servo direction
bench		Outputs; MANUAL mode, then ANGLEroll right: left elevon down, right up; pitch back: both up; ANGLE, tilt right: left up, right down; ANGLE, nose down: both up. Wrong on both axes — a negative rate; on one axis — the sign of that axis's weight in that servo's smix. Reversing on the radio is not allowedno reversals left in the servo test table
Center and end points
bench		Outputs; CLI servo <n> <min> <max> <mid> <rate>mechanical center: all servos at 1500, horns perpendicular to the pushrods, the remainder with mid. Full roll plus full pitch, min/max without binding, e.g. servo 2 1100 1900 1500 -100no servo buzzes with full stick on the diagonal
Control throws
bench		a ruler; CLIh = c·sin δ at the trailing edge; 60 mm chord: 8° → 8.4 mm, 12° → 12.5 mm, 15° → 15.5 mm. Without a manual, ±12° in roll. Reduce manual_roll_rate/manual_pitch_rate (MANUAL) and roll_rate/pitch_rate, not min/maxthrows within ±1 mm of the calculation
Center of gravity
bench		calculation from the geometry (aero-wing), balancing on fingertipsCG at 15–20 % MAC; example (1.20 m span, 280/170 mm chords): 126–138 mm from the root leading edge, target 133 mm; balance with the battery, GPS and camera installed; the forward limit is safer. Horizon in ANGLE — fw_level_pitch_trim (degrees, + = nose up)the wing hangs level or slightly nose down on the fingertips, the point is within range
Battery
bench field		CLIthe same formulas as for the quad: 1100 × 16.42 / 16.08 = 1123; 250 × 2860 / 3180 = 225 (the FC counted less, so scale goes down). Without a current sensor — current_meter_type = VIRTUALbelow 0.05 V per cell, mAh within 5 %
Failsafe
SITL bench		CLIfailsafe_procedure = RTH, failsafe_delay = 5, failsafe_throttle_low_delay = 0 (mandatory, otherwise it disarms while gliding), failsafe_fw_roll_angle = -200, failsafe_fw_pitch_angle = 100, failsafe_fw_yaw_rate = -45. Bench: arm in ANGLE, throttle 30 %, switch off the radioafter 0.5 s the OSD shows FAILSAFE; without a fix — the LAND spiral (bank left, nose down)
RTH and loiter
SITL field		CLInav_rth_altitude = 5000, nav_rth_allow_landing = NEVER, nav_fw_loiter_radius = 6000, fw_loiter_direction = RIGHT. Bank tan φ = V²/(g·R) no more than nav_fw_bank_angle (35°): 15 m/s and 60 m → 20.9°the RTH loiter has a radius of 60 ± 15 m
Auto launch and the first throw
bench field		Modes: NAV LAUNCH; CLInav_fw_launch_thr = 1700, nav_fw_launch_motor_delay = 500, nav_fw_launch_climb_angle = 18, nav_fw_launch_timeout = 5000, nav_fw_launch_max_altitude = 3000, nav_fw_launch_max_angle = 45. Bench without the prop: a sharp forward movement → throttle after 0.5 s. Field: the prop goes on here, wind ≤ 5 m/s, throw into the wind. Abort: bank over 45° or a nose dip in the first 2 s — MANUAL, throttle to zero; no climb within 5 s — throttle to zero, landthe log shows the throw, the 0.5 s delay and throttle 1700
Autotrim and autotune
field		Modes: SERVO AUTOTRIM, AUTO TUNESERVO AUTOTRIM in level flight in ANGLE, hold for 2 s, do not switch it off until disarmed. AUTO TUNE at ≥ 50 m, 3–5 min, changes only FF and rates; save after disarming with the stick commandnew mid and fw_ff_* values in diff all after the flight

ArduCopter 4.7

Module: ArduPilot from scratch: Copter with Mission Planner / QGC. Version: 4.7 (checked against 4.7.2; the steps marked SITL were run on Copter-4.6.3). “Where”: a Mission Planner (MP) or QGroundControl (QGC) screen / a parameter.

Propellers off. Props go on only at step 15. Plug in the battery only when an item calls for it; the flight controller is on USB.
Step · environmentWhereWhat to set / checkDone when
1. Firmware, backup
SITL bench		MP: Install Firmware; QGC: Vehicle Setup → Firmwarethe first time — DFU (BOOT + USB), arducopter_with_bl.hex, STM32CubeProgrammer; after that only .apj. Before that, a diff all from Betaflight. Backup: MP Config → Full Parameter List → Save, QGC Parameters → Tools → Save to file, MAVProxy param save 00_defaults.param00_defaults.param is saved before the first change
2. Frame, orientation
SITL		MP Full Parameter List / QGC ParametersFRAME_CLASS = 1 (Quad), FRAME_TYPE = 1 (X) or 12 (BetaFlightX); AHRS_ORIENTATION if the board is rotated; reboot. SITL: -f X (-f quad is Plus, FRAME_TYPE = 0)after the reboot the values are in place, no errors in MP Messages
3. Ports
SITL		ParametersSERIALn_PROTOCOL: 2 MAVLink2, 5 GPS, 23 RCIN, 16 ESC telemetry, 42 DisplayPort. SERIALn ↔ UARTx per the board's hwdef table. Rebootthe ports are assigned per the board's UART table
4. Receiver
bench		ParametersSERIALn_PROTOCOL = 23, RC_PROTOCOLS = 512 (bit 9, CRSF), RC_OPTIONS = 8736 (32 + 512 + 8192), RSSI_TYPE = 3. Bind; switch the radio on before the receiver. In SITL set RC_PROTOCOLS = 1 back after the checkthe channels move in Radio Calibration
5. Channels, radio calibration
bench		MP: Radio Calibration; QGC: Radioall sticks and switches to their end positions, then center → RCn_MIN/MAX/TRIM; RCMAP_ROLL/PITCH/THROTTLE/YAW = 1/2/3/4. ELRS ≈ 988…2012 µsthrottle with the radio off is at least 10 µs below FS_THR_VALUE (975), and with the radio on and the stick down at least 10 µs above it
6. Motor protocol
SITL bench		ParametersMOT_PWM_TYPE: 0 PWM, 1 OneShot, 2 OneShot125, 4/5/6/7 DShot150/300/600/1200; reboot. DShot: SERVO_DSHOT_ESC = 1 (BLHeli32/AM32) or 2 (BLHeli_S/Bluejay), SERVO_BLH_AUTO = 1, bidir — SERVO_BLH_BDMASK (15 = outputs 1–4), SERVO_BLH_POLES (14); if SERVO_BLH_BDMASK is not in the list, flash the board's -bdshot variant; EDT — SERVO_DSHOT_ESC 3 or 4. RC_SPEED is for PWM only. Do not mix DShot and PWM in one timer group (ap-outputs)after the reboot MOT_PWM_TYPE is kept and the motors respond
7. Order and direction
SITL bench		MP: Motor Test, Mandatory Hardware → Servo Output; MAVProxy motortest10 % (if it does not spin, 15 %). Letters go clockwise from the front right: A → output 1, B → 4, C → 2, D → 3. Quad X: 1 front right CCW, 2 rear left CCW, 3 front left CW, 4 rear right CW. Direction: DShot — SERVO_BLH_RVMASK or ESC Configurator, PWM — swap two wires. Position — SERVOn_FUNCTION (33–36 = Motor1–4) on the Servo Output screen (which also has Min/Trim/Max, Reverse and the live output pulse)the “button → output → position → direction” table matches the frame diagram
8. ESC (PWM only) and idle
bench		Parameters; Motor TestPWM: ESC_CALIBRATION = 3, unplug USB and the battery, plug in the battery, safety, a tune and beeps per cell count, unplug. DShot is not calibrated. The start threshold in Motor Test, e.g. 6 % → MOT_SPIN_ARM = 0.08 (threshold + 0.02), MOT_SPIN_MIN ≥ MOT_SPIN_ARM + 0.03armed without props, all motors spin evenly and none stands still
9. Accel and compass
bench field		MP: Accel Calibration, Onboard Mag Calibration6 positions + Calibrate Level; Onboard Mag Calibration outdoors, three tones, reboot (COMPASS_CAL_FIT 16 by default, 32 only as a last resort; COMPASS_AUTO_ROT = 2 fixes the external compass orientation); with a mast compass, the internal compass gets COMPASS_USEn = 0 for its priority (check COMPASS_PRIOn_ID; USE2 is the second priority, not necessarily the internal one). CompassMot later: below 30 % is good, 31–60 % is a gray zone, above 60 % move the compassno “PreArm: Compass not calibrated”
10. Battery monitor
SITL bench		MP: Battery Monitor; ParametersBATT_MONITOR = 4. V = (V_pin − BATT_VLT_OFFSET) × BATT_VOLT_MULT; I = (V_pin − BATT_AMP_OFFSET) × BATT_AMP_PERVLT. Order: zero, voltage, current, mAh. BATT_AMP_OFFSET new = old + I₀ / BATT_AMP_PERVLT; BATT_VOLT_MULT new = old × V_multimeter / V_GCS; BATT_AMP_PERVLT new = old × mAh_charged / mAh_FC (BAT.CurrTot), example 40 × 1310 / 1186 = 44.2voltage error below 0.02 V per cell (0.12 V on 6S), mAh within 5 %
11. Modes, arming
SITL		MP: Flight ModesFLTMODE_CH = 5; in pairs: FLTMODE1/2 = 0 Stabilize, FLTMODE3/4 = 2 AltHold, FLTMODE5/6 = 5 Loiter. Arming — RCx_OPTION = 153 or ARMING_RUDDER = 2; E-Stop — RCx_OPTION = 31. Leave ARMING_SKIPCHK = 0 alone (before 4.7, ARMING_CHECK = 1); PreArm:/Arm: texts — see the module's “Why it won't arm” tableevery switch position lights up the right mode
12. Failsafe
SITL bench		ParametersRC: FS_THR_ENABLE = 1 (RTL), FS_THR_VALUE = 975, RC_FS_TIMEOUT = 1 s. 6S: BATT_LOW_VOLT = 21.6, BATT_CRT_VOLT = 21.0, BATT_FS_LOW_ACT = 2 (RTL), BATT_FS_CRT_ACT = 1 (Land), BATT_ARM_VOLT = 22.1, BATT_CAPACITY, BATT_LOW_MAH (by default BATT_FS_LOW_ACT = 0 — beeping only). SITL: SIM_RC_FAIL = 1, without RC override (RC_OVERRIDE_TIME = 3 s). Bench: Stabilize, arm, throttle to zero, switch off the radioSITL: the log has ERR Subsys=5 and Subsys=6 with a switch to RTL; bench: an immediate disarm
13. OSD
bench		ParametersOSD_TYPE = 1 (MAX7456) or 5 (MSP DisplayPort) + SERIALn_PROTOCOL = 42 on the VTX port; OSD_CHAN switches screens. HD: OSDn_TXT_RES 0 — 30×16 (default), 1 — 50×18, 2 — 60×22; MSP_OPTIONS 0, 4 — Betaflight font (DJI O3/O4), 8 — INAV; reboot (ap-osd-video)the goggles show voltage, mode, RSSI/LQ
14. GPS and RTL
SITL		Parameters; MP MessagesGPS1_TYPE = 1; RTL_ALT_M in meters (default 15; before 4.7 RTL_ALT in centimeters, 1500), above the site's obstacles“EKF3 IMU0 is using GPS” — without it Loiter will not engage

field		MP: Initial Parameter SetupMOT_THST_HOVER = 0.25, ATC_THR_MIX_MAN = 0.1, MOT_HOVER_LEARN = 2, LOG_DISARMED = 0, an SD card. A 20 × 20 m area, wind below 5 m/s.
