CourseDesignerCapstone project

An aircraft built to a spec

Track 3 capstone projectPASSED

Result: An aircraft design for a given mission: calculations, a powertrain test on the stand (or from the dataset), stability or mixer, prediction compared with measurement

Expected result

  • The spec in numbers: payload, flight time, wind, dimensions, margin
  • A sizing script in the repository with a closed mass budget and the configuration choice
  • Thrust stand data for the chosen motor/prop pair (your own or from the module dataset): g/W, C_T, uncertainty budget
  • For a wing: CG and static margin; for a non-standard multirotor: the effectiveness matrix and a saturation check
  • If the aircraft is built: a hover or flight log and a comparison with the prediction

Acceptance criteria

Track modules

  1. Designing for a mission: spec → mass, energy, thrust, configuration
  2. Thrust stand: load cell + HX711, current, RPM, efficiency
  3. The plane: stability, CG, static margin, drag polar
  4. Mixer and control allocation: the matrix, saturation, PX4 Control Allocation, tilted motors
Safety. Everything you can do in SITL or without props, you do there. Real flights only after ground tests, with a verified failsafe.
