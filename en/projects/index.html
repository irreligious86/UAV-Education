Projects: UAS software

Twelve software projects, from a web GCS to precision landing on a marker. Each comes with an architecture diagram, stages, acceptance criteria and an automated test; where a starter exists, it's in the repository's examples/. A project can replace its track's capstone project.

How to work: take a project, complete the modules on its list, do the stages in order, submit against the criteria. Code goes in your own repository with a README and tests; “works on my machine” doesn't count.
