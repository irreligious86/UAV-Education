Сервис анализа логов

Проект 3L3~25 честь стартерСДАН

Из лога полёта — отчёт с находками: вибрации и клиппинг, просадка и внутреннее сопротивление АКБ, ошибки, GPS, ошибка слежения по углам. Каждая находка с порогом и объяснением, отчёт — один HTML-файл.

Стек

  • Python, pymavlink
  • blackbox_decode (Betaflight)
  • matplotlib → встроенные SVG/PNG
  • pytest на синтетических логах

Стартер: examples/log-report — клонируйте и начинайте с его README.

Может заменить итоговый проект трека «Интегратор».

Этапы

  1. Разбор DataFlash: VIBE, BAT, ERR, GPS, ATT, MODE, MSG
    Проверка: pytest examples/log-report/tests -k "clean_flight or vibration or battery"
  2. Проверки с порогами и severity, JSON-вывод
    Проверка: pytest examples/log-report/tests -k err_and_gps
  3. HTML-отчёт с графиками и таймлайном режимов
    Проверка: pytest examples/log-report/tests -k cli_writes
  4. Вход Betaflight Blackbox через blackbox_decode
    Проверка: демонстрация в отчёте
  5. Проверки EKF (XKF4) и регрессия на собственных логах
    Проверка: демонстрация в отчёте

Критерии приёмки

Проект сдан, когда выполнены все пункты. Отмечайте по мере готовности:

Автопроверка

pytest examples/log-report/tests (5 тестов на синтетических логах)

Оценка

Сдан — когда выполнены все критерии приёмки. Уровень работы — по критериям ниже; каждый уровень включает предыдущий.

  • Функциональность
    • Засчитано: Все этапы работают в сценарии из README
    • Хорошо: Плюс отказные сценарии: потеря связи, пропуск данных, неверный ввод
    • Отлично: Плюс хотя бы одно задание «на отлично» из списка проекта
  • Проверяемость
    • Засчитано: Тесты стартера проходят, свои функции покрыты хотя бы одним тестом
    • Хорошо: Тест на каждый этап; тесты запускаются в CI
    • Отлично: Тесты на отказы и регрессию на собственных данных; покрытие ключевой логики видно в отчёте
  • Инженерный отчёт
    • Засчитано: Есть замеры, которых требуют критерии приёмки
    • Хорошо: Замеры с методикой и повторяемостью (несколько прогонов, разброс)
    • Отлично: Сравнение вариантов решения с выводом, ограничения и что делать дальше
  • Код и документация
    • Засчитано: README: запуск одной командой, архитектура
    • Хорошо: Модули разделены, интерфейсы описаны, нет «магических чисел» без пояснения
    • Отлично: Код читается без автора: docs/, примеры, история коммитов по этапам

Задания «на отлично»

  • Регрессия: 10 своих логов с известным вердиктом, сервис ни разу не ошибается
  • Сравнение двух логов «до/после» тюна одним отчётом

Что сдать

  • Инструмент + README
  • Три отчёта по своим логам и сравнение с ручным разбором

Нужные модули

  1. Логи ArduPilot: разбор полёта
  2. Blackbox
  3. Python для анализа полётных данных
  4. Дерево диагностики: дрон не взлетает
  5. Тюнинг ArduPilot: AUTOTUNE, фильтры, notch по ESC
Безопасность. Всё, что управляет аппаратом, сначала проходит тесты и SITL. Реальный полёт — только с проверенным failsafe и пилотом, готовым забрать управление.
