INAV Programming Framework

L3 — Специалистчтение 25 минучёба ~3 чINAV 7.0+ОСВОЕН

INAV Programming Framework (IPF) — способ добавить аппарату логику без Lua и без companion: «если дальше 100 м — поднять мощность VTX», «если напряжение ниже порога — включить RTH», «переключить канал по условию». Логические условия выполняются прямо в прошивке, работают с телеметрией, режимами, точками миссии и глобальными переменными. Модуль объясняет модель (условие = операция + два операнда), синтаксис CLI, GVAR и типичные применения, включая сравнение с Lua в ArduPilot.

После модуля ты умеешь
  • собрать логическое правило с активатором
  • использовать GVAR как состояние

Теория

Модель

  • Logic Condition — одна строка «кода»: операция над одним-двумя операндами, с результатом true/false или числом.
  • Операнд — число, канал RC, параметр полёта (расстояние до дома, напряжение, высота, скорость), режим, другое условие, GVAR, точка миссии.
  • Активатор — другое условие, которое должно быть true, чтобы это выполнилось (−1 — всегда).
  • GVAR — глобальные переменные, целые от −32768 до 32767; их можно читать, писать, увеличивать и использовать в миксере серв.
  • Programming PID — четыре настраиваемых регулятора, выход которых доступен как операнд.

Синтаксис CLI

logic <rule> <enabled> <activatorId> <operation> <opA type> <opA value> <opB type> <opB value> <flags>

Типы операндов: 0 — значение, 1 — RC-канал, 2 — параметр полёта, 3 — режим, 4 — логическое условие, 5 — GVAR. Операции: сравнения (равно, больше, меньше), логические (AND, OR, NOT), арифметика, Set/Increase/Decrease GVAR, Override Throttle Scale, Override RC Channel, Set VTX power и другие.

Пример из документации: мощность VTX по удалению

Условие 0: «расстояние до дома > 100 м». Условие 1 (активатор 0): «установить мощность VTX = 3». Два правила — и передатчик сам поднимает мощность, когда аппарат далеко.

Где IPF уместен

  • автоматика на борту без второго компьютера: VTX, свет, PINIO, сервы;
  • условные действия в миссии через user actions;
  • защиты: переключение режима по напряжению или удалению;
  • приборные задачи: GVAR как счётчики и состояния.

Против Lua в ArduPilot

Lua — полноценный язык с доступом к API автопилота, но требует F7/H7 и памяти. IPF — набор правил без циклов и функций, зато работает на F4 и настраивается из конфигуратора. Сложная логика в IPF быстро становится нечитаемой; граница — десяток-два правил.

Практика

Шаг 1. Первая пара правил в конфигураторе

Вкладка Programming: правило 0 — Flight > Home distance (m) больше 100; правило 1 — активатор 0, операция Set VTX Power, значение 3. Сохранить, проверить вкладку: состояние условий показывается вживую.

Шаг 2. То же в CLI

logic 0 1 -1 2 2 <home_distance_operand_id> 0 100 0
logic 1 1 0  <set_vtx_power_op_id> 0 3 0 0 0
save

Номера операций и операндов — из таблиц в документации Programming Framework для своей версии: они меняются между релизами, поэтому в модуле не зашиты.

Шаг 3. GVAR как состояние

Правило: по срабатыванию тумблера увеличить GVAR 1 на 1; другое правило — если GVAR 1 чётная, включить свет, иначе выключить. Это конечный автомат на двух строках.

Лабораторная

Собрать защиту: если напряжение ниже порога и расстояние больше 50 м — переопределить канал режима в положение RTH (Override RC Channel). Проверить на земле с имитацией через стенд или в SITL INAV, затем в поле на малом удалении.

Диагностика

Симптом: правило не срабатывает

  • Возможная причина: активатор false, неверный тип операнда (GVAR «значение 1» против «GVAR 1»).
  • Что сделать: смотреть живое состояние во вкладке Programming, проверить типы.

Симптом: Set GVAR пишет не в ту переменную

  • Возможная причина: в операнде A указан «Global Variable 1» вместо «Value 1».
  • Что сделать: индекс GVAR задаётся как Value.

Симптом: после обновления INAV правила сломались

  • Возможная причина: изменились номера операций/операндов.
  • Что сделать: сверить с таблицами версии, пересобрать правила.

Симптом: логика стала нечитаемой

  • Возможная причина: слишком много правил для IPF.
  • Что сделать: упростить или перейти на Lua/ArduPilot.
