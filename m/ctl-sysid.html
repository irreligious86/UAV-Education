Идентификация системы: чирп, частотная характеристика, модель для тюнинга

L4 — Экспертчтение 40 минучёба ~3 чArduCopter 4.5+ · Python 3 + NumPyОСВОЕН

Тюнинг «на глаз» и даже AUTOTUNE отвечают на вопрос «какие коэффициенты», но не «почему». Идентификация системы отвечает: аппарату подают известный сигнал (чирп — синусоиду с растущей частотой), записывают реакцию, считают частотную характеристику и подгоняют под неё модель с понятными параметрами — постоянной времени моторов, задержкой, коэффициентом усиления. С моделью тюнинг становится расчётом: запас по фазе, частота среза, что даст фильтр. Модуль разбирает чирп и требования к эксперименту, режим SYSID в ArduCopter, оценку частотной характеристики по спектрам, подгонку модели первого порядка с задержкой и использование модели для выбора коэффициентов. Код проверяется на синтетических данных, затем — на логе SITL.

После модуля ты умеешь
  • спланировать и провести эксперимент с чирпом
  • оценить частотную характеристику и подогнать модель с задержкой
  • рассчитать запас по фазе и цену фильтра по модели

Теория

Зачем модель

  • Регулятор настраивают под объект. Объект рейт-контура коптера — «команда момента → угловая скорость»: инерция корпуса, постоянная времени моторов (разгон винта), задержки (фильтры, ESC, расчётный цикл).
  • Модель вида G(s) = K·e^(−sτ) / (Ts + 1) (или с интегратором — для перехода к углу) описывает эту цепочку тремя числами. Зная их, можно посчитать запас по фазе для любых коэффициентов, увидеть, сколько фазы «съест» новый фильтр, и сравнить два аппарата объективно.
  • Модуль «Теория управления» дал язык (передаточные функции, запасы); здесь — как получить модель из полёта.

Чирп и требования к эксперименту

  • Чирп — синусоида, частота которой растёт от f₀ до f₁ за время записи. Экспоненциальный (логарифмический) чирп тратит одинаковое время на каждую октаву — удобно для логарифмической оси частот.
  • Диапазон частот: от ниже ожидаемой полосы контура (1–2 Гц) до выше частоты среза (30–60 Гц для небольших коптеров), но ниже частот, где шум и резонансы рамы.
  • Амплитуда: достаточно большая, чтобы сигнал был выше шума, и достаточно малая, чтобы не выйти в насыщение моторов и нелинейность. Признак насыщения — моторы на пределе в логе.
  • Длительность: десятки секунд — больше периодов на низких частотах, точнее оценка.
  • Замкнутый контур. Аппарат летит с работающими регуляторами, поэтому вход и выход связаны через регулятор. Важно, куда вводится сигнал и что берётся «входом»: оценивают отношение выхода к реальному сигналу на входе объекта (например, к выходу регулятора/миксера), а не к заданию.

Режим SYSID в ArduCopter

  • Режим «как STABILIZE», который подмешивает чирп в выбранную точку контура и пишет данные в лог (сообщения SIDD — данные во времени, SIDS — настройки).
  • SID_AXIS — куда подмешивать (угол, рейт или миксер по крену/тангажу/рысканию и др.; значения — по списку своей версии). Пока SID_AXIS = 0, войти в режим нельзя.
  • SID_MAGNITUDE — амплитуда, SID_F_START_HZ и SID_F_STOP_HZ — диапазон, SID_T_REC — длительность записи, SID_T_FADE_IN/SID_T_FADE_OUT — плавное нарастание и спад амплитуды.
  • Безопасность: высота, свободное пространство, пилот готов перехватить управление переключением режима; начинать с малой амплитуды, сначала в SITL.
  • Betaflight и PX4: штатного режима чирпа в Betaflight нет (анализ — по Blackbox при ручных возмущениях); в PX4 автотюн коптера сам идентифицирует модель онлайн, а для ручной идентификации есть сигнал-генераторы в тестовых сборках — по документации своей версии.

Частотная характеристика по спектрам

Для линейной системы Y(f) = H(f)·U(f). Оценка H = (Y·U*) / |U|², усреднённая по полосам частот: перекрёстный спектр делить на спектр входа. Усреднение по полосе подавляет шум; там, где во входе мало энергии (за пределами чирпа), оценка бессмысленна.

  • Когерентность (качество оценки) — насколько выход объясняется входом линейно: близко к 1 — хорошо; падает — шум, нелинейность, другой вход (ветер, пилот).
  • Результат — точки на диаграмме Боде: усиление в дБ и фаза в градусах.

Подгонка модели

Модель G(s) = K·e^(−sτ) / (Ts + 1):

  • на низких частотах усиление ≈ K;
  • на частоте излома 1/(2πT) усиление −3 дБ, фаза −45° (без задержки);
  • задержка τ не меняет усиление, но добавляет −360°·f·τ фазы, растущей с частотой. Поэтому T видно по усилению, τ — по «лишней» фазе на высоких частотах.

Подгонка — минимизация разницы комплексных H и G по точкам (перебор по сетке T и τ, K — аналитически). На примере модуля (T = 20 мс, τ = 10 мс, шум на выходе) подгонка возвращает T = 20 мс и τ ≈ 9 мс: модель непрерывная, а данные — дискретные с шагом 2.5 мс, полшага задержки «теряется».

Модель → тюнинг

  • Запас по фазе. Для пропорционального регулятора Kp разомкнутый контур L = Kp·G. Частота среза — где |L| = 1; запас по фазе — 180° + ∠L на ней. Чем больше Kp, тем выше частота среза и тем меньше запаса из-за задержки.
  • Цена фильтра. Фильтр нижних частот с частотой f_c добавляет примерно −arctan(f/f_c) фазы: на частоте среза контура 20 Гц фильтр 80 Гц отнимает ~14°. Это и есть «фильтры съедают запас» из модуля «Фильтры» — теперь числом.
  • Сравнение аппаратов и изменений. Новые винты, моторы, рама — новая модель: видно, изменилась ли постоянная времени или задержка, и сколько коэффициентов это стоит.

Практика

Шаг 1. Синтетическая проверка

Код идентификации и подгонки; сначала — на данных с известным ответом:

import numpy as np

def identify(u, y, fs, f_lo=1.0, f_hi=40.0, nbins=30):
    """Frequency response y/u in log-spaced bins (cross-spectrum / auto-spectrum)."""
    U, Y = np.fft.rfft(u), np.fft.rfft(y)
    f = np.fft.rfftfreq(len(u), 1 / fs)
    edges = np.geomspace(f_lo, f_hi, nbins + 1)
    out = []
    for lo, hi in zip(edges[:-1], edges[1:]):
        k = (f >= lo) & (f < hi)
        if k.any():
            H = np.sum(Y[k] * np.conj(U[k])) / np.sum(np.abs(U[k]) ** 2)
            out.append((np.sqrt(lo * hi), H))
    return np.array([o[0] for o in out]), np.array([o[1] for o in out])

def fit_first_order_delay(fq, H):
    """Grid search K, T, tau for K e^{-s tau} / (T s + 1)."""
    s = 2j * np.pi * fq
    best = None
    for T in np.arange(0.002, 0.1, 0.001):
        for tau in np.arange(0.0, 0.05, 0.0005):
            G = np.exp(-s * tau) / (T * s + 1)
            K = np.real(np.vdot(G, H) / np.vdot(G, G))
            err = np.sum(np.abs(H - K * G) ** 2)
            if best is None or err < best[0]:
                best = (err, K, T, tau)
    return best[1:]

if __name__ == "__main__":          # synthetic check: chirp through a known plant
    fs, dur = 400.0, 20.0
    t = np.arange(0, dur, 1 / fs)
    k = 40.0 ** (1 / dur)
    u = np.sin(2 * np.pi * (k ** t - 1) / np.log(k))
    a, d = np.exp(-1 / (fs * 0.02)), int(0.01 * fs)
    y = np.zeros_like(u)
    for i in range(1, len(u)):
        y[i] = a * y[i - 1] + (1 - a) * (u[i - d] if i >= d else 0)
    y += np.random.default_rng(1).normal(0, 0.02, len(y))
    fq, H = identify(u, y, fs)
    K, T, tau = fit_first_order_delay(fq, H)
    print(f"K = {K:.2f}, T = {T * 1000:.0f} мс, τ = {tau * 1000:.1f} мс")
# K = 1.00, T = 20 мс, τ = 9.0 мс

Диагностика

Симптом: точки частотной характеристики «скачут»

  • Возможная причина: малая амплитуда относительно шума, короткая запись, ветер или вмешательство пилота.
  • Что сделать: больше амплитуда (без насыщения), длиннее запись, тихая погода, руки прочь от стиков.

Симптом: на высоких частотах фаза уходит без меры

  • Возможная причина: реальная задержка больше модели, фильтры, резонанс рамы.
  • Что сделать: оценивать модель в диапазоне, где она применима; резонансы — отдельно (notch).

Симптом: модель хорошо легла, а коэффициенты по ней раскачивают аппарат

  • Возможная причина: оценка «задание → выход» вместо «вход объекта → выход» в замкнутом контуре.
  • Что сделать: брать входом реальный сигнал на объект (выход регулятора/миксера).

Симптом: моторы упираются в пределы во время чирпа

  • Возможная причина: слишком большая амплитуда, низкий запас тяги.
  • Что сделать: снизить SID_MAGNITUDE, проверить газ висения.

Симптом: не входит в режим SYSID

  • Возможная причина: SID_AXIS = 0, параметры не обновлены.
  • Что сделать: выставить ось, обновить параметры в наземке.
