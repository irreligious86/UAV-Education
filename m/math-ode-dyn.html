Дифференциальные уравнения и динамика: от мотора до контура

PID-тюнинг «на глаз» заканчивается там, где начинается понимание, *что именно* настраивают. Модуль даёт минимальный аппарат: уравнение первого порядка и постоянная времени (мотор, фильтр, задержка смешанная с инерцией), уравнение второго порядка и его три режима (апериодический, критический, колебательный), полюса как «адрес» поведения системы на комплексной плоскости, передаточная функция как способ собирать блоки умножением, и — то, без чего ни одна формула не попадёт в прошивку, — дискретизация: Эйлер, Тастин, что теряется при шаге 1/8000 с и при 1/50 с. Теория

Уравнение первого порядка

Самая частая модель в дроне: τ·ẋ + x = K·u. Так ведёт себя тяга мотора в ответ на команду ESC, выход RC-фильтра, температура, заряд конденсатора. Решение при скачке входа u = 1 с нуля: x(t) = K·(1 − e^(−t/τ)). За время τ выход проходит 63 % пути, за 3τ — 95 %, за 5τ — 99 %. Постоянная времени τ — единственный параметр динамики; её же называют «задержкой мотора», хотя это не задержка, а инерция: мотор начинает реагировать сразу, но плавно.

Как найти τ по логу: на скачке команды найти момент, где отклик достиг 63 % установившегося значения. Для 5" мотора с пропом τ ≈ 15–30 мс, для 15" — 80–150 мс. Именно τ ограничивает, насколько «злым» можно сделать D-term: D усиливает высокие частоты, а мотор их всё равно не отработает — только нагреется.

Частотная сторона того же уравнения: это фильтр нижних частот с частотой среза f_c = 1/(2πτ). Фильтр гироскопа 100 Гц — это τ = 1.6 мс «инерции», добавленной в контур.

Уравнение второго порядка

ẍ + 2ζω₀·ẋ + ω₀²·x = ω₀²·u. Два параметра: собственная частота ω₀ (рад/с) и коэффициент затухания ζ. - ζ > 1 — апериодический режим: медленно подползает без перелёта. - ζ = 1 — критическое затухание: самый быстрый приход без перелёта. - 0 < ζ < 1 — колебательный: перелёт и затухающие колебания частотой ω₀√(1 − ζ²); перелёт в процентах ≈ 100·e^(−πζ/√(1 − ζ²)) (ζ = 0.5 → 16 %, ζ = 0.7 → 5 %). - ζ = 0 — незатухающие колебания; ζ < 0 — неустойчивость, амплитуда растёт.

Ось квадрокоптера с P-регулятором угла — ровно это уравнение: инерция J·θ̈ = момент, момент = K_p·(θ_цель − θ) − K_d·θ̇. Тогда ω₀ = √(K_p/J), ζ = K_d/(2√(K_p·J)). Отсюда правило, которое знает каждый тюнер, не зная формулы: поднял P — колебания участились и перелёт вырос; поднял D — перелёт упал. А I-term добавляет третий порядок и способен превратить ζ в отрицательное — «I-колебания» низкой частоты при слишком большом I.

Полюса: адрес поведения

Любое линейное уравнение с постоянными коэффициентами имеет решения вида e^(st); подставив, получаем характеристическое уравнение, а его корни s — полюса. Для первого порядка полюс один: s = −1/τ. Для второго: s = −ζω₀ ± ω₀√(ζ² − 1).

Читать карту полюсов на комплексной плоскости: - Действительная часть отрицательна — устойчиво; чем левее, тем быстрее затухает (время затухания ≈ 4/|Re s|). - Мнимая часть — частота колебаний (рад/с). - Полюс в правой полуплоскости — неустойчивость: любая ошибка растёт. - Полюс на мнимой оси — граница: незатухающие колебания (так ведёт себя контур с P, поднятым до самовозбуждения).

Передаточная функция

Для линейных систем с нулевыми начальными условиями дифференцирование по времени превращается в умножение на s (преобразование Лапласа). Первый порядок: G(s) = K/(τs + 1). Второй: G(s) = ω₀²/(s² + 2ζω₀s + ω₀²). PID: C(s) = K_p + K_i/s + K_d·s. Блоки соединяются умножением (последовательно) и формулой замкнутого контура: T(s) = C·G/(1 + C·G). Полюса замкнутого контура — корни 1 + C(s)G(s) = 0: вот где живут «правильные» значения PID. Чистая задержка (транспорт пакета, фильтр) — e^(−sL): она не меняет амплитуду, но поворачивает фазу на ω·L, и именно она делает контур неустойчивым при больших усилениях. Запас по фазе — сколько ещё задержки можно добавить до самовозбуждения; у боевой 5" с хорошим тюном он 40–60°.

Дискретизация: формулы для прошивки

Контроллер работает по тактам с периодом T_s (Betaflight — PID loop 4–8 кГц, ArduPilot — 400 Гц, PX4 rate loop — до 1 кГц). Производную и интеграл заменяют разностями: - Эйлер назад: ẋ ≈ (xₖ − xₖ₋₁)/T_s; ∫x ≈ Σ xₖ·T_s. Просто, но вносит задержку T_s/2 и искажает частоты выше f_s/10. - Тастин (билинейное): s → (2/T_s)·(z − 1)/(z + 1). Сохраняет устойчивость и частотную характеристику точнее; все фильтры Betaflight (biquad) и PT1 дискретизованы именно так или через точную формулу RC-фильтра. - PT1 первого порядка в коде: yₖ = yₖ₋₁ + k·(xₖ − yₖ₋₁), где k = T_s/(τ + T_s) — это обратное преобразование Эйлера, при f_c ≪ f_s практически точное. В Betaflight — pt1FilterGain(). - Что ломается при большом T_s: частота Найквиста f_s/2 — всё выше неё заворачивается; производная шума растёт как 1/T_s; при T_s, сравнимом с τ, Эйлер вперёд может сделать устойчивую систему неустойчивой. Правило: период цикла не больше τ/10 самого быстрого процесса, который контур должен отрабатывать.

Задержка против инерции

Их путают, а они разные: инерция (τ) — плавная реакция, начинающаяся сразу; задержка (L) — ничего не происходит, потом точная копия входа. Контур с инерцией можно «разогнать» усилением почти без предела; контур с задержкой — нет: при усилении K фазовый запас выедается, и при ω·L ≈ 1–1.5 рад контур колеблется, что ни делай. Для 5": L ≈ 2–4 мс (фильтры + RC) при τ ≈ 20 мс. Поэтому мантра «меньше фильтров — острее дрон» верна ровно до того момента, пока шум не начнёт греть моторы.

Практика

Шаг 1. Одна ось с PID в numpy

Модель: J·θ̈ = M − b·θ̇, мотор как первый порядок с τ_m, PID по угловой скорости с дискретным шагом T_s и фильтром D-term PT1.

import numpy as np

def sim_axis(kp, ki, kd, tau_m=0.02, J=1.0, b=0.2, Ts=1/2000, T=1.0, d_cut=100.0, setpoint=1.0):
    """One rate axis: PID -> first-order motor -> inertia. Returns t, rate, motor command."""
    n = int(T / Ts); t = np.arange(n) * Ts
    rate = np.zeros(n); u = np.zeros(n); m = 0.0; integ = 0.0; d_f = 0.0; prev = 0.0
    k_d = Ts / (1 / (2 * np.pi * d_cut) + Ts)                       # PT1 gain for the D-term filter
    for k in range(1, n):
        err = setpoint - rate[k - 1]
        integ += err * Ts
        d_raw = -(rate[k - 1] - prev) / Ts; prev = rate[k - 1]       # derivative on measurement
        d_f += k_d * (d_raw - d_f)
        u[k] = kp * err + ki * integ + kd * d_f
        m += (u[k] - m) * Ts / tau_m                                  # motor: first-order lag
        acc = (m - b * rate[k - 1]) / J
        rate[k] = rate[k - 1] + acc * Ts
    return t, rate, u

Постройте отклик на скачок для (kp, ki, kd) = (1, 0, 0), (3, 0, 0), (3, 0, 0.05), (3, 5, 0.05). Найдите kp, при котором начинаются незатухающие колебания; измерьте их частоту и сравните с полюсами, вычисленными по формуле второго порядка. Сравните поведение с виджетом в модуле ctl-theory при тех же параметрах.

Реализуйте PT1-фильтр 100 Гц тремя способами (Эйлер вперёд, Эйлер назад, точная формула k = T_s/(τ + T_s)) при T_s = 1/8000 и 1/100. Подайте синус 50 Гц. Диагностика

Симптом: при подъёме P контур колеблется на частоте, которая не зависит от P

  • Возможная причина: это задержка, а не инерция: ω·L ≈ π/2; частота задаётся суммарной задержкой.
  • Что сделать: уменьшить задержку (фильтры, RC smoothing), а не крутить P.

Симптом: медленные (1–2 Гц) раскачивания при хорошем быстром отклике

  • Возможная причина: слишком большой I — третий полюс ушёл вправо.
  • Что сделать: снизить I или добавить anti-windup/ограничение I.

Симптом: модель в numpy неустойчива, хотя аналитика говорит «устойчиво»

  • Возможная причина: шаг интегрирования слишком велик (Эйлер вперёд) относительно τ.
  • Что сделать: T_s ≤ τ/10 или неявная схема.

Симптом: D-term шумит, моторы горячие, а отклик не острее

  • Возможная причина: D усиливает частоты выше 1/τ_m, которые мотор не отрабатывает.
  • Что сделать: фильтр D-term на уровне ~1/(2πτ_m)·3, меньше D, RPM-фильтр.
