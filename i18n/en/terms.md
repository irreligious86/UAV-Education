# Terminology: Russian → English

Binding for every translation of the course (interface, modules, quizzes, tasks, glossary). Plain technical
English, American spelling, second person ("you"), the same direct and slightly informal tone as the
original. Parameter names, commands, MAVLink messages, flight-mode names, code and unit symbols are never
translated (`ATC_RAT_RLL_P`, `ARMING_CHECK`, `Loiter`, `AltHold`, `failsafe`, `ROS 2`, `MAVLink`). Use the
terms the ArduPilot / PX4 / Betaflight documentation uses.
