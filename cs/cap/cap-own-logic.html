КурсИнженер: код на бортуИтоговый проект

Своя логика + ESP32-модуль

Итоговый проект трека 7СДАН

Результат: работающий модуль, протокол обмена, README и тесты

Что должно получиться

  • Репозиторий: firmware/, lua/ или companion-сервис, docs/
  • Протокол обмена: каждое сообщение, поля, кто имеет право слать
  • README с установкой и запуском
  • Тесты: эхо/heartbeat, таймаут, отказ companion
  • Демонстрация в SITL (и в воздухе — только с геозоной и пилотом)
  • Инженерная папка проекта: требования с ID, что и как тестировалось, журнал изменений (см. модуль «Инженерный метод 101»)

Критерии готовности

Проверяешь себя сам: проект готов, когда каждый пункт выполнен и ты можешь это показать числом, логом или тестом. Отмечай по мере готовности:

Рубрика самопроверки: как отличить готовое от сделанного наполовину

Проверь свою работу по каждой строке. Если она ближе к левой колонке — проект ещё не готов.

КритерийПлохоХорошо
КодСкрипт без тестовРепозиторий с README, тестами в SITL, CI, журналом изменений
ИнтеграцияРаботает «иногда»Таймауты, обработка потери связи, лог поведения при отказе
ДокументацияНетДругой инженер может повторить развёртывание по README за 15 минут
СистемностьПодсистемы описаны по отдельности: что с чем связано и как решение в одной меняет другие, не показаноСхема блоков с интерфейсами; у каждого решения названо с числом влияние на соседние подсистемы (масса, питание, задержка, отказы); аномалия прослежена по цепочке от причины до реакции системы

Программная альтернатива

Итоговый проект трека можно заменить проектом из каталога «ПО для БАС» — с теми же требованиями: критерии готовности, автотесты, README.

  • Проект 2: Телеметрия флота в облако + дашборд
  • Проект 8: MAVLink-компонент на ESP32 + SITL-двойник
  • Проект 9: Мост 4G/Wi-Fi с переподключением и шифрованием
  • Проект 10: CI/CD для флота
  • Проект 12: Компаньон для пульта TX16S

  15. Companion + ArduPilot: управление из кода

  17. Свои сборки прошивок

  19. Системная инженерия: требования, FMEA, документация, тесты
  20. CI и версионирование конфигов и кода
