КурсПроектыПроект 6

Инспекция маршрута с геопривязкой находок

Проект 6L3~30 честь стартерСДАН

Миссия вдоль линии (ЛЭП, трубопровод, забор), съёмка по расстоянию, автоматическая привязка кадров к координатам и отчёт с находками на карте.

Стек

  • ArduPilot миссии, CAM1_TRIGG_DIST / DO_SET_CAM_TRIGG_DIST
  • EXIF/XMP геотеги
  • Python, Leaflet-отчёт

Стартер: examples/inspection — клонируйте и начинайте с его README.

Может заменить итоговый проект трека «Автономия».

Этапы

  1. Генератор миссии вдоль полилинии с перекрытием
    Проверка: pytest examples/inspection/tests -k "offset or mission"
  2. Съёмка по расстоянию, лог CAM с обратной связью затвора (CAM1_FEEDBAK_PIN)
    Проверка: демонстрация в отчёте
  3. Сопоставление кадров с лог-записями CAM, запись геотегов
    Проверка: pytest examples/inspection/tests -k "matching or naive"
  4. Разметка находок и отчёт-карта
    Проверка: pytest examples/inspection/tests -k geojson
  5. Проверка точности привязки по контрольным точкам
    Проверка: демонстрация в отчёте

Критерии приёмки

Проект сдан, когда выполнены все пункты. Отмечайте по мере готовности:

Автопроверка

тест сопоставления на фикстурах (лог CAM + набор EXIF)

Оценка

Сдан — когда выполнены все критерии приёмки. Уровень работы — по критериям ниже; каждый уровень включает предыдущий.

  • Функциональность
    • Засчитано: Все этапы работают в сценарии из README
    • Хорошо: Плюс отказные сценарии: потеря связи, пропуск данных, неверный ввод
    • Отлично: Плюс хотя бы одно задание «на отлично» из списка проекта
  • Проверяемость
    • Засчитано: Тесты стартера проходят, свои функции покрыты хотя бы одним тестом
    • Хорошо: Тест на каждый этап; тесты запускаются в CI
    • Отлично: Тесты на отказы и регрессию на собственных данных; покрытие ключевой логики видно в отчёте
  • Инженерный отчёт
    • Засчитано: Есть замеры, которых требуют критерии приёмки
    • Хорошо: Замеры с методикой и повторяемостью (несколько прогонов, разброс)
    • Отлично: Сравнение вариантов решения с выводом, ограничения и что делать дальше
  • Код и документация
    • Засчитано: README: запуск одной командой, архитектура
    • Хорошо: Модули разделены, интерфейсы описаны, нет «магических чисел» без пояснения
    • Отлично: Код читается без автора: docs/, примеры, история коммитов по этапам

Задания «на отлично»

  • Терраин-фоллоуинг по DEM на холмистом участке
  • Автоматическая выборка кадров для находок по модели, а не вручную

Что сдать

  • Генератор миссии, инструмент привязки, отчёт по одному маршруту

Нужные модули

  1. Миссии и планирование
  2. Камеры и видеопоток на companion
  3. Картографирование: съёмка, геопривязка, фотограмметрия
  4. Геометрия камеры: от пикселя до точки на земле
  5. GNSS: как работает GPS, ошибки, RTK
  6. Полевые операции и работа команды
Безопасность. Всё, что управляет аппаратом, сначала проходит тесты и SITL. Реальный полёт — только с проверенным failsafe и пилотом, готовым забрать управление.
