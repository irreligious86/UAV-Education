Детектор + трекер + следование в Gazebo

Проект 4L4~45 честь стартерСДАН

Камера в симуляторе → детектор (YOLO-nano или цветовой) → трекер → регулятор, который держит цель в центре кадра и на заданной дистанции через скоростные setpoint'ы в Offboard/GUIDED.

Стек

  • ROS 2 Humble
  • Gazebo + PX4 или ArduPilot SITL
  • OpenCV, ONNX Runtime
  • examples/ros2-docker

Стартер: examples/follow-target — клонируйте и начинайте с его README.

Может заменить итоговый проект трека «Восприятие и интеллект».

Этапы

  1. Поток камеры из Gazebo в ROS 2, замер FPS
    Проверка: демонстрация в отчёте
  2. Детектор с метриками на записанном bag
    Проверка: демонстрация в отчёте
  3. Трекер с ID и предсказанием при пропусках
    Проверка: демонстрация в отчёте
  4. Регулятор следования (стартер: follow.py — чистая функция с ограничениями и сторожем потери цели), замер задержки
    Проверка: pytest examples/follow-target/tests
  5. Сценарий в симуляторе с движущейся целью и потерей цели
    Проверка: демонстрация в отчёте

Критерии приёмки

Проект сдан, когда выполнены все пункты. Отмечайте по мере готовности:

Автопроверка

тест регулятора как чистой функции + прогон на записанном bag

Оценка

Сдан — когда выполнены все критерии приёмки. Уровень работы — по критериям ниже; каждый уровень включает предыдущий.

  • Функциональность
    • Засчитано: Все этапы работают в сценарии из README
    • Хорошо: Плюс отказные сценарии: потеря связи, пропуск данных, неверный ввод
    • Отлично: Плюс хотя бы одно задание «на отлично» из списка проекта
  • Проверяемость
    • Засчитано: Тесты стартера проходят, свои функции покрыты хотя бы одним тестом
    • Хорошо: Тест на каждый этап; тесты запускаются в CI
    • Отлично: Тесты на отказы и регрессию на собственных данных; покрытие ключевой логики видно в отчёте
  • Инженерный отчёт
    • Засчитано: Есть замеры, которых требуют критерии приёмки
    • Хорошо: Замеры с методикой и повторяемостью (несколько прогонов, разброс)
    • Отлично: Сравнение вариантов решения с выводом, ограничения и что делать дальше
  • Код и документация
    • Засчитано: README: запуск одной командой, архитектура
    • Хорошо: Модули разделены, интерфейсы описаны, нет «магических чисел» без пояснения
    • Отлично: Код читается без автора: docs/, примеры, история коммитов по этапам

Задания «на отлично»

  • Метрики детектора по срезам дистанции и освещённости
  • Повторное захватывание цели после 3 с потери без смены ID

Что сдать

  • ROS 2 пакет, launch, README
  • Видео и график ошибки положения цели в кадре

Нужные модули

  1. Камеры и видеопоток на companion
  2. Компьютерное зрение: от OpenCV до нейросетей
  3. Слежение и управление по цели
  4. ML на борту: бюджет, квантование, оценка, сопровождение
  5. ROS 2 + PX4: uXRCE-DDS, offboard-узел как автомат состояний
  6. Архитектура бортового приложения на ROS 2: узлы, lifecycle, watchdog
Безопасность. Всё, что управляет аппаратом, сначала проходит тесты и SITL. Реальный полёт — только с проверенным failsafe и пилотом, готовым забрать управление.
