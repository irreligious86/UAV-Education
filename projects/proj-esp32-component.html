MAVLink-компонент на ESP32 + SITL-двойник

Проект 8L3~30 честь стартерСДАН

ESP32 как полноценный MAVLink-компонент: свой heartbeat и compid, датчик (дальномер или ток) в DISTANCE_SENSOR/BATTERY_STATUS, приём команд. Python-двойник того же компонента проходит те же тесты против SITL и фейкового аппарата.

Стек

  • ESP-IDF или PlatformIO, C
  • c_library_v2
  • Python-двойник (examples/mavlink)
  • ArduPilot SITL

Стартер: examples/mavlink — клонируйте и начинайте с его README.

Может заменить итоговый проект трека «Инженер: код на борту».

Этапы

  1. Python-двойник проходит тесты (стартер: virtual_rangefinder.py)
    Проверка: pytest examples/mavlink/tests -k rangefinder
  2. Прошивка ESP32: UART MAVLink, heartbeat, DISTANCE_SENSOR
    Проверка: демонстрация в отчёте
  3. Приём COMMAND_LONG с ACK
    Проверка: pytest examples/mavlink/tests -k "arm_command or rejected"
  4. Автопилот использует компонент (RNGFND1_TYPE=10) — проверено в логе
    Проверка: демонстрация в отчёте
  5. Стенд: ESP32 ↔ USB-UART ↔ SITL на ПК
    Проверка: демонстрация в отчёте

Критерии приёмки

Проект сдан, когда выполнены все пункты. Отмечайте по мере готовности:

Автопроверка

pytest examples/mavlink/tests как основа; добавить тесты своего компонента

Оценка

Сдан — когда выполнены все критерии приёмки. Уровень работы — по критериям ниже; каждый уровень включает предыдущий.

  • Функциональность
    • Засчитано: Все этапы работают в сценарии из README
    • Хорошо: Плюс отказные сценарии: потеря связи, пропуск данных, неверный ввод
    • Отлично: Плюс хотя бы одно задание «на отлично» из списка проекта
  • Проверяемость
    • Засчитано: Тесты стартера проходят, свои функции покрыты хотя бы одним тестом
    • Хорошо: Тест на каждый этап; тесты запускаются в CI
    • Отлично: Тесты на отказы и регрессию на собственных данных; покрытие ключевой логики видно в отчёте
  • Инженерный отчёт
    • Засчитано: Есть замеры, которых требуют критерии приёмки
    • Хорошо: Замеры с методикой и повторяемостью (несколько прогонов, разброс)
    • Отлично: Сравнение вариантов решения с выводом, ограничения и что делать дальше
  • Код и документация
    • Засчитано: README: запуск одной командой, архитектура
    • Хорошо: Модули разделены, интерфейсы описаны, нет «магических чисел» без пояснения
    • Отлично: Код читается без автора: docs/, примеры, история коммитов по этапам

Задания «на отлично»

  • Параметры компонента через PARAM_* (свой компонент в списке параметров GCS)
  • Подпись MAVLink 2 между ESP32 и автопилотом

Что сдать

  • Прошивка, двойник, тесты, лог SITL с датчиком

Нужные модули

  1. Свой компонент MAVLink: датчик, параметры, сообщения
  2. MAVLink изнутри: кадр, CRC, диалекты, подпись
  3. ESP32 и периферия
  4. UART, I2C, SPI, CAN на уровне сигналов и драйверов
  5. SITL: дрон без дрона
Безопасность. Всё, что управляет аппаратом, сначала проходит тесты и SITL. Реальный полёт — только с проверенным failsafe и пилотом, готовым забрать управление.
