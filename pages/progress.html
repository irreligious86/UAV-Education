Мой прогресс

Балл модуля = 40% квиз (лучшая попытка) + 60% лабораторная; в модулях с задачами — 30% квиз + 30% задачи + 40% лабораторная. «Освоен» — квиз ≥ 80%, все задачи решены и все пункты лабораторной. Ручная отметка видна как «отмечен», это честно другое.

Весь курс

Итоговые проекты

  • Паспорт своей сборки
  • Свой квадро от стола до первого полёта
  • Бортовая электрика с расчётом
  • Настройка по логам
  • Свой фильтр ориентации
  • Окто X8 с нагрузкой или VTOL-крыло
  • Своя логика + ESP32-модуль
  • Слежение за целью

Проекты «ПО для БАС»

  • Проект 1: Веб-GCS: телеметрия, карта, режимы
  • Проект 2: Телеметрия флота в облако + дашборд
  • Проект 3: Сервис анализа логов
  • Проект 4: Детектор + трекер + следование в Gazebo
  • Проект 5: Точная посадка на маркер в симуляции
  • Проект 6: Инспекция маршрута с геопривязкой находок
  • Проект 7: Фотограмметрия на открытом наборе
  • Проект 8: MAVLink-компонент на ESP32 + SITL-двойник
  • Проект 9: Мост 4G/Wi-Fi с переподключением и шифрованием
  • Проект 10: CI/CD для флота
  • Проект 11: Пакет защит на Lua с тестами
  • Проект 12: Компаньон для пульта TX16S

Результаты грейдеров

Грейдеры курса (examples/sitl-pymavlink/check_lab_log.py, examples/blackbox-grader/check_bf_log.py) с флагом --json result.json пишут файл результата. Загрузи его — пункты лабораторных, которые грейдер действительно проверил и которые прошли, отметятся сами; в таблице они помечены «⚙». Это самопроверка: файл можно подделать, он показывает, что грейдер запускали, а не что кто-то принял работу.
