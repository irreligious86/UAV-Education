# PX4 track fixes — 2026-11-15

Fixes for `docs/reviews/px4-coverage-audit.md` §7.3 (13 items). Every item was checked against the PX4 source before any
edit. Primary source: tag **v1.15.4** (`/tmp/px4-audit`), the version the course states. Tags **v1.16.2** and **v1.17.0**
were used for the version notes. Tag **v1.14.0** was read from `raw.githubusercontent.com` for two files, because
`px4-intro`/`px4-control`/`px4-architecture` claim "1.14+": `rc.mc_defaults` and `imu_gyro_parameters.c`. Both match 1.15.4:
RATEMAX 400 → 800 for MC, RTL 30/10, `IMU_DGYRO_CUTOFF` 30.

Nothing was committed and `publish.py` was not run. `validate_content.py` reports OK before and after the edits (140 articles,
140 quizzes). In every edited `.md` file the `##` headings, the `{{…}}` directives and the code-fence count are unchanged.
The JSON banks still parse, and every answer index is still valid. Only Russian source files under `content/` were edited.
The generated pages (`m/`, `en/`, `cs/`, `uk/`, `ode/`, `api/`) and the `i18n/` translations were left alone. `i18n/en` holds
the old text for `px4-intro`, `px4-architecture` and `math-ode-dyn`, so the translation owners need to re-sync it.
