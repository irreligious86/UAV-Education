# Diagrams

Infographics for modules are inline SVG files generated by a small Python toolkit. No external
libraries, no raster images, no network: diagrams inherit the page's colours via CSS variables,
work offline (PWA) and in both themes.

## Authoring

1. Add a diagram to `scripts/diagrams/build_diagrams.py` — first-wave and hand-built diagrams — or
   to `scripts/diagrams/wave2.py` (one per module that had none; grouped by track), or drop a
   hand-written SVG into `assets/diagrams/<id>.svg`. Ids: `[a-z0-9-]+`. Text budget: about 19
   characters per line in a 150 px box, 16 in the narrow boxes of a five-column row — render and look
   before committing; long labels overflow silently.
2. Run `python3 scripts/publish.py` — it regenerates `assets/diagrams/`, runs
   `scripts/check_diagrams.py`, then validates and builds the site.
3. Reference the diagram from a module on a line of its own, with a caption:

   ```
   {{diagram:fc-signal-path|Путь сигнала: гироскоп → фильтры → PID → миксер → ESC.}}
   ```

   The caption is Russian prose that states what the reader should take from the picture
   (not a repetition of the title). The validator rejects a tag without a caption or with a
   missing file; the checker warns about generated diagrams nobody references.

## Toolkit (`scripts/diagrams/svg.py`)

| Primitive | Use for | Signature |
|---|---|---|
| `flow(title, boxes, links, w, h, notes)` | data flow, system architecture | `Box(id, label|lines, x, y, w, h, accent)`, link `(from, to, label, accent, route)` |
| `frame(title, fields, width, unit, note)` | byte/bit layout of a protocol frame | field `(name, size, accent, sub)`; sqrt-scaled widths |
| `timeline(title, lanes, t_max, width, unit, marks)` | timing / stage diagrams | lane `(name, [(t0, t1, label, accent)])` |
| `tree(title, root, width, ...)` | decision trees | `Node(id, label|lines, [(edge_label, Node)], accent, leaf)` |
| `sequence(title, actors, steps, width, notes)` | message sequence charts (protocol dialogues) | step `(from, to, label, accent, dashed)`; from == to → note |

Rules enforced by `scripts/check_diagrams.py` (CI): well-formed XML, `<svg>` root with
`viewBox` and `<title>`, no `<script>`, `<image>` or external `href`, ≤ 60 KB per file, every
referenced id exists.

Style: monospace labels, `currentColor` ink, accent `--gc-accent-hud`, panels `--gc-surface-200`.
Canvas 720 px wide; on phones the figure scrolls horizontally (min 600 px) so labels stay legible.
Keep labels short (a box line ≈ 18 characters at 12 px) and check the render:
`node` + Playwright screenshot, or open the module page at 390 px width.
