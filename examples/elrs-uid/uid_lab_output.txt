== 2. What goes over the air from the UID (phrase my-quad-2026) ==
FHSS seed = UID[2..5] with UID[5]^4 = 0x550F9B22
CRC init  = (UID[4]<<8 | UID[5]) ^ 0x0400 = 0x9F26
UID[0], UID[1] never go over the air: OtaUidIsBound() looks only at UID[2..5]

== 4. Model Match: UID5 in the SYNC packet ==
UID5 = 38 = 0b00100110; mask 0x3F = low 6 bits, model ID 0…63
TX Model Match Off ID None -> UID5 in SYNC =  38;  RX stores ID Off (0xFF) -> link, channels flow
TX Model Match On  ID 1    -> UID5 in SYNC =  24;  RX stores ID 1          -> link, channels flow
TX Model Match On  ID 2    -> UID5 in SYNC =  27;  RX stores ID 1          -> link up, no channels (Model Mismatch)
TX Model Match On  ID 0    -> UID5 in SYNC =  25;  RX stores ID Off (0xFF) -> link up, no channels (Model Mismatch)
TX Model Match Off ID None -> UID5 in SYNC =  38;  RX stores ID 1          -> link up, no channels (Model Mismatch)
TX Model Match On  ID 65   -> UID5 in SYNC =  24;  RX stores ID 1          -> link, channels flow
ID 65 & 0x3F = 1: numbers 1 and 65 are indistinguishable (EdgeTX only offers 0…63 anyway)
